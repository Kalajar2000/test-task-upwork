Deliverable 01 · Landing Page

One offer. Four real variations.

The brief was a registration page for the same free masterclass as the control funnel — built from scratch, not cloned. So each variant here tests a different angle, different copy and different structure, not just a different coat of paint. Every page ships with a guided rationale tour (gold button, bottom-left) explaining each variation hypothesis, and every form tags its funnelVersion for clean split-test attribution. Proof assets (photos, win videos, community screenshots, reviews) are the client's real ones; every sentence of copy is original.

Variant 01 · VSL

VSL — "Watch First, Then Decide"

"Two Minutes Now, Or Ninety Later. Start Here."

Warm-traffic hypothesis: retargeted visitors convert off a face-to-camera video, not more sections. One player, one CTA, three answers, done. (Placeholder clip — production drops in the real VSL.)

How I'd run this: v1 and v2 split cold ad traffic, v4 takes the retargeting audience, v3 runs against v1 for organic/community traffic.
